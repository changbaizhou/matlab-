# MATLAB geomorphology project

Study areas: Xiying River mountain catchment and a segment of the Lenglongling with north and south slopes.

See the accompanying tutorial `地貌参数操作步骤_完善版.docx` in the course folder for data acquisition, setup, and reproducibility steps.

Raw Copernicus DEM tiles are retained under `data/raw`. MATLAB cache and analysis files are excluded from Git because they are reproducible and exceed GitHub's 50 MB warning threshold. The TecGeoTools dependency is excluded; follow the pinned commit and license instructions in the tutorial.
